gpt4free's API Route provider requires an API key and uses your API Route account balance. Dify's contribution is a chat provider plugin accepted in the official plugin repository; install the plugin before configuring a key and exact model ID. Embeddings use another provider. SourceGit's documentation was merged into develop. Memorix, ChunkHound, and opencode-mem configure embeddings separately, and ChunkHound reranking is separate as well. nanoMuse's own-key chat is billed to your API Route balance and does not include picture input, image generation, or video. AI-Infra-Guard's accepted change is an Agent Scan target preset; the scanner's own model configuration stays separate. CCS documents an Anthropic-compatible base URL without `/v1`, and llama.vscode uses `https://global.api-route.com` without `/v1`. These merge records do not establish availability in every published app version or in Dify Marketplace.
