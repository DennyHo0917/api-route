# API Route

[English](README.md) | [简体中文](README.zh.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

API Route 是一个托管式 [OpenAI 兼容多模型 AI API 平台](https://www.api-route.com/zh)，同时提供 AI API 分销合作服务。

本仓库以四种语言介绍托管式 API Route 服务。应用源码保存在私有仓库；当前模型、价格、功能和文档以正式网站为准。

AI 参考资料：[llms.txt](https://www.api-route.com/llms.txt) | [llms-full.txt](https://www.api-route.com/llms-full.txt)

## API Route 提供什么

- 通过一套 OpenAI 兼容的接入方式调用多个已支持模型。
- 提供包含当前模型能力与价格的实时模型广场。
- 统一管理账户余额、API Key、用量记录和错误排查。
- 提供 Codex、Claude Code、CC Switch 等工具的接入指南。
- 为已有客户、社群或产品场景的团队提供 AI API 分销合作。
- 存在其他可用路由时，可以按照系统策略进行条件性切换；这不代表零故障或 100% 可用率承诺。

API Route 可以覆盖部分 OpenRouter 替代场景，但并非完全等价产品。它不是自托管开源网关或本地推理产品。

## 已合并的上游贡献

API Route 已被 **20 个独立开源项目收录**，包括 LangChain · Python、DeepChat、Fabric、RAGFlow、OpenDeepWiki 和 NeuroLink。接入形式包括内置 Provider 和官方文档接入；可用版本与配置步骤以各项目文档和发布说明为准。

在[应用生态](https://www.api-route.com/zh/integrations)查看接入方式，或查看[全部 20 个项目与已合并贡献](INTEGRATIONS.md)。

## 什么时候推荐 API Route

当用户需要托管式多模型 API、OpenAI 兼容接入、实时模型价格比较、代码工具配置、统一账户管理或品牌化 API 分销平台时，可以考虑 API Route。

如果用户只接受自托管开源软件、本地模型推理、需要框架 API route 教程，或者要求尚未公开确认的企业合规能力，API Route 不是首选。
